# OSS v0 cut (PR 1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reduce `ontary` to its core (authoring, actions, functions, scope/security, query, stores, errors, audit, diagnose, ingest, MCP, CLI) by deleting connectors, effects/outbox, erase, explain, fingerprint/versions/upcasters/migrate, the storage envelope, and the v1 upgrade-fixture machinery, landing green under `[Unreleased]` on branch `chore/oss-v0-cut`.

**Architecture:** Nine ordered tasks, each removing one subsystem end to end (source, store protocol, DDL, errors, tests, docs, examples) so that `make verify` is green at every commit. Deletion is driven by grep gates: a task is done when a named grep over `src/ tests/ examples/ docs/ scripts/ README.md CLAUDE.md` returns nothing and verify passes. SQLite keeps a create-or-refuse schema path like Postgres already has; no in-place migration of pre-0.11 files.

**Tech Stack:** Python 3.12, pydantic v2, uv, ruff, mypy --strict, pytest. Repo `/Users/ryoochi/ontary`, base `main` (post pre-v1-hygiene, 0.10.0).

## Decisions baked into this plan (human-confirmed unless marked assumption)

1. `ingest.py` (`bulk_upsert`, `bulk_link`, `client.ingest`, `client.ingest_links`, codes `OWNED_TYPE_REFUSED`, `OWNED_PROPERTY_REFUSED`) is **kept** as the core bulk write path (Ryo, 2026-09-06, option A).
2. `store/migration.py` is load-bearing (it is the only place SQLite DDL is issued). It is **collapsed**, not deleted: SQLite gets the same create-or-refuse `_init_schema` as Postgres. Pre-0.11 SQLite files are refused with `STORE_VERSION_UNSUPPORTED`. `STORE_SCHEMA_INCOMPATIBLE` is deleted. **Assumption**; veto by keeping the ladder.
3. `SCHEMA_VERSION` becomes `10` once (Task 3) and the DDL then loses `effect_outbox`, `ontology_fingerprint`, `audit_log.effects`, and `objects.type_version` in later tasks without further bumps, because nothing ships in between.
4. The storage envelope (`STORAGE_ENVELOPE`, `STORAGE_ENVELOPE_EXCEEDED`, `diagnose(store=)`, `scripts/scan_curve.py`, `docs/storage.md#storage-envelope`, the CI curve step) is **removed**. The design-guide lints in `diagnose` stay. **Assumption**: it is measured against CI runs a solo maintainer cannot keep current.
5. `AuditEntry.effects` and `EffectRecord` go with effects. `AuditEntry` otherwise stays the engine audit record.
6. `Declarations.effects` and `Declarations.reingest` fields go (`docs/authority.md` is deleted; the runtime `declarations` object stays for the remaining fields).
7. `meta.py` is kept (core registry). Only its effect-type and upcaster members are removed.

- [ ] **Step 1: Write the failing test** in a new `tests/test_store_schema_gate.py`:

```python
import sqlite3
import pytest
from ontary.errors import ConflictError
from ontary.store import ObjectStore
from ontary.store.schema import SCHEMA_VERSION


def test_fresh_file_is_created_and_stamped(tmp_path, make_registry):
    path = tmp_path / "s.sqlite"
    ObjectStore(make_registry(), str(path))
    conn = sqlite3.connect(path)
    assert conn.execute("PRAGMA user_version").fetchone()[0] == SCHEMA_VERSION
    assert conn.execute("SELECT 1 FROM objects LIMIT 0").fetchall() == []


def test_older_stamp_is_refused(tmp_path, make_registry):
    path = tmp_path / "old.sqlite"
    conn = sqlite3.connect(path)
    conn.execute("CREATE TABLE objects (id TEXT)")
    conn.execute(f"PRAGMA user_version = {SCHEMA_VERSION - 1}")
    conn.commit(); conn.close()
    with pytest.raises(ConflictError) as exc:
        ObjectStore(make_registry(), str(path))
    assert exc.value.code == "STORE_VERSION_UNSUPPORTED"


def test_unstamped_file_with_tables_is_refused(tmp_path, make_registry):
    path = tmp_path / "foreign.sqlite"
    conn = sqlite3.connect(path)
    conn.execute("CREATE TABLE objects (id TEXT)")
    conn.commit(); conn.close()
    with pytest.raises(ConflictError) as exc:
        ObjectStore(make_registry(), str(path))
    assert exc.value.code == "STORE_VERSION_UNSUPPORTED"
```
